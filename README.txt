SERRA standalone — no install, no build.
Best: double-click index.html (Chrome/Edge). If videos don't scrub, run a tiny server in this folder:  python3 -m http.server  then open http://localhost:8000
Keep the media folder next to index.html.

To set the phone number: open index.html, search for PHONE near the top of the script, replace +910000000000 with your number.
